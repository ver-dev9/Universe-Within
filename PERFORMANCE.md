# PERFORMANCE & OPTIMIZATION — UNIVERSE WITHIN

## 1. Performance Goals & Benchmarks
- **Target Framerate:** 60 FPS constant on modern desktop GPUs (Apple Silicon, NVIDIA GTX 1060+, AMD Radeon RX 580+).
- **Target Mobile Framerate:** 45–60 FPS on iOS and modern Android devices.
- **Initial Asset Payload:** Less than 1.5 MB uncompressed bundle (HTML + JS + CSS).
- **Initial Network Requests:** 0 external image or audio asset requests.

---

## 2. Core Optimization Strategies

### A. Procedural Canvas Texture Baking
External 4K JPEG/PNG planetary textures typically require 50–150 MB of network bandwidth, create visual pop-in (FOUT), and frequently suffer CORS blockages.
- All planetary surface textures in this project are dynamically synthesized onto 1024x512 HTML5 canvases on application startup.
- Canvas textures are cached in `src/utils/textureGenerators.ts` so each body is only generated once.
- Mipmapping is automatically generated by Three.js for hardware-accelerated anisotropic filtering.

### B. Instanced Buffer Attributes
- Over 5,000 stars in `Starfield.tsx` and 1,800 nebula particles in `NebulaDust.tsx` are rendered via single instanced `THREE.Points` draw calls using packed `Float32Array` attributes.
- Draw call count is kept below 35 across the entire 3D solar system.

### C. Dynamic DPR & Power Preference
```typescript
<Canvas
  dpr={[1, 2]} // Clamps maximum device pixel ratio to 2 to prevent 4K/Retina GPU fillrate saturation
  gl={{
    powerPreference: 'high-performance',
    antialias: true,
    alpha: true
  }}
>
```

### D. Single Animation Loop & Controlled RAF
- All camera movements, planet rotations, and solar pulse effects are registered inside React Three Fiber's unified `useFrame` render loop rather than through independent `setInterval` or disjointed `requestAnimationFrame` hooks.
- Eliminates thread lock and prevents battery drain when the browser tab is blurred.

---

## 3. Memory & Resource Disposal
All Three.js geometries and canvas textures are registered for clean WebGL context lifecycle management, preventing browser memory leaks during extended exploration sessions.
